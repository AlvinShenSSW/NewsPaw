# M02 / #20 — durable same-partition model execution

## Spec review and frozen contract
Turn a frozen news request into a validated model result through the configured primary/backup. Reuse identical evidence, locale and editorial scope on every attempt; never fetch RSS/X or send Telegram here. Every paid dispatch has a unique durable attempt linked atomically to its budget reservation. Lost responses and crash windows become outcome_unknown with retained holds, never an automatic retry/fallback. Known transient/configuration/format/refusal/no-news outcomes remain distinct. Failed tasks remain inspectable without returning raw source text as a final brief.

Acceptance: bounded retries including format repair, Retry-After and persistent cooldown; same-partition eligible backup only; validation (including caller's frozen citation validator) after every attempt/repair/recovery. Durable success reused across Bot fanout/delivery retries. Full preflight before each side effect. No raw credentials/errors or reasoning in records. No unbounded self-repair, cross-group routing or fabricated provider idempotency.

## Authority / assumptions
M01 gives normalizedtext/vision/function requests and independent current capability lookup. F02 effective route snapshot binds model configuration, source membership, target language and readiness. Caller supplies existing route snapshot, frozen evidence identifier/hash and request; all must match current configuration. M02 owns no source collection or arbitrary tools. Supported production adapters currently have no verified non-billable result-query/idempotency contract: all unknown outcomes stop. A narrow trusted adapter recovery method is exercised by fixtures only; a config flag cannot enable it. Live provider behavior remains unverified, no real calls in this development issue.

A request contains a trusted operation/version tag, ModelRequest fields (excluding executable validator), evidence hash/count, route fingerprint and task budget/policy. The caller re-supplies its trusted validator on resume; the operation/version and serialized schema/request digest must match. Models cannot choose validators, operation tags, URLs or targets. In-process trusted pipeline API only, not a new general-purpose model RPC. Text/inline-vision supported by M01; bounded inline bytes may be frozen as base64 in private SQLite for crash recovery, never in logs or public repo. O01/D03 own retention/temporarymedia policy; no claims about finishedmedia cleanup in M02.

## Storage and APIs
Add model_runner.py with ModelRunner and small SQLite helpers; schema7 tables:
- model_tasks: stable task_id, partition, route_snapshot JSON, operation/version, evidence identity/count, request digest/bounded JSON, policy/total task cap, state, next_at, result JSON, last safe failure.
- model_attempts: stable task/ordinal ID, profileID/generation/identity, budgetattemptID, state, repair flag, started/finished, safe outcome/result/usage.
- model_health: profileID/generation, consecutive failure count, cooldown_until, last error/time. One backend/SQLite, no queue broker/ORM/framework.
The same taskID+same immutable request returns its existing state/result; changed arguments reject idempotency conflict. TaskID excludes Bot. New attempt IDs derived from task+ordinal, unique acrossrestart; repair/fallback share sameBudgetLedger task_id and task_limit. A source-empty task becomes no_news without credential/modelcalls. Pause/stale/invalidroute blocksbeforeanydispatch; Q03 later owns subscription task scheduling.

Methods submit/advance(task_id,...), status(task_id), recover_interrupted() under owned startup. Task creation freezes request and route; advance obtains an instance async lock (one paid task at a time is adequate for this single-user app) plus durable state checks so duplicate caller instances cannot dispatch the same task. No await inside DB transaction. A taskalreadyinflight is pending, never replayable. Terminal completed/refused/no_news/cancelled/stale/outcome_unknown/blocked returns storedstate. Waiting task mayadvance only at/after next_at; no busy sleep inside executor.

## Retry / failure policy
Freeze taskpolicy with attempts_per_profile default2, allowed1..3; eachattemptincludingformatrepaircounts. Max total is two selectedprofiles times allowance; no hiddenloop. Domain output format repair at mostonce perprofile and withinsameallowance; append fixedrepairinstruction to samefrozenevidence/schema, neverrelaxcitationsorforwardarbitrarymodelinstructions. Validator rerun on everyresult. Exhaustedprimary mayuse eligible samepartitionbackup; exhaustedboth taskblockedwithfailurehistory, neverrawsourcefallback.
- Connect/pre-dispatchfailure, known429ratelimit andknown5xx: retryafter safeheader (numericseconds orawareHTTPdate) else short bounded backoff; taskwaiting untilduedate. No in-requestsleep/replay. Quotaexhaustion/401/403/404/400: visibleconfiguration/provider failure, no sameconfigurationretry; tryeligiblebackup ifbudgetpermits. Sourceempty/Telegramerror are notinputs to thisfailurepath.
- Refusal/contentfilter: taskrefused, zeroautomaticbackup/formatrepair.
- Read/write/ambiguous transport or resultpersistencecrash: outcome_unknown, zeroautomaticretry/backup, oldholdkept.
- invalid/incompleteformat: one boundedrepair, theneligiblebackup. Citationvalidatorfailure is thisknownformatfailure, not a license to fabricate.
- Budgetdenial: retainblockedtask/cause, noalternatecapbypass. An explicitresume afteroperatorbudget/configaction requiresnewpreflight, keepssame taskcap andattemptcount; neverreset spentamounts.
Profilehealth accumulates transienterrors across tasks;3 consecutive transientfailures starts5mincooldown (orlongerRetry-After). Duringcooldown skipprofile withvisiblehealthreason andtryeligiblebackup. Afterexpiry, one ordinary bounded newsattempt serves as half-openhealthprobe (no extra syntheticpaidcall); successresetshealth,failureextendscooldown. The single runner lock avoids concurrenthalf-open dispatch in actualsinglebackend. Configurationerrors suspend that profilegeneration until configidentitychanges or explicitnew successfulcapabilityprobe afterfailure; status remainsvisible. Stored profilegeneration prevents inheritedhealth poisoning a replacement.

## Unknown-outcome recovery contract
No builtinproductionprovider is marked recoveryverified. If a trusted adapter explicitly implements a verified, non-billable, read-only resultlookup contract, recovery mayquery onceperoperator/runnerinvocation withoutdispatchinggeneration. Queryfailure/notfound/nonterminal staysunknown. A confirmedcompleted result must pass the samefrozenvalidator and currentroutechecks, then persistresult/settleholdatomically. Confirmeddefinitelyunsent requires a conclusive contract, notgeneric404; mayreconcileoldhold0 and allowboundednextattempt. No automatic idempotent generation reissue is implemented. Fixtures cover capable/incapableadapters; claim remainsconditional, neverenabledbyuntrustedconfig/modeldata. A normalunknown taskrequires explicitoperatorresolution or duplicate-charge retry authorization, notperiodicautomaticgeneration; expose a narrow explicitretry method carrying acknowledgement, preservingoldholds andsame taskbudget/attemptlimits.
