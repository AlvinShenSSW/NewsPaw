## 本次补齐的产品决策

下列为 Codex 根据已确认需求确定的实施默认值，不冒充用户已经选择了具体时间、预算或源名单。实现验收以 `requirements.md` 为准。

- 现有五页 mockup 是唯一界面基线；保留当前 Logo、分类图标、布局和关联关系，只增补实现必需的状态/校验。
- 普通/成人是数据属性；分类、源、账号、证据、任务、缓存都携带分区，模型不能自行更改。混合或未分类输入先等待范围选择。
- 特别关注账号默认从所属 X 合并简报中排除，避免每日重复；用户可显式纳入。普通/成人分别处理。
- 计划时间表示目标推送时间，采集与生成提前准备；超时显示晚点，不能保证电脑睡眠时准点。默认补最新一期，补发窗口沿用 6 小时建议，可配置。
- DST 不存在的本地时刻顺延到首个有效时刻；重复时刻只发一次。期次以订阅、当地日期、计划槽 ID 唯一标识，而非仅偏移时间。
- 尚未开始的投递遇到语言/路由/分区改变就失效重算；已部分发送的版本暂停剩余部分，保留回执，由用户决定补发，避免一期混语言/分区。
- 总预算、X 资源读量和生图预算用持久化预留与结算控制并发；未知用量保留预留，不显示虚假的实际账单。
- 低频源不按“24 小时未更新”一律判故障；新鲜度与连通性分开，日期未知不能成为今天新闻。
- 群组推送、多用户、云驻守、自动安装推荐 repo/skill 不在首版；视频理解、重大事件提醒为明确后续 issue，默认关闭。

## 外部依赖与未决项

第二个 AV 站名；真实 Bot/X/API 凭据与账户权限；具体生图主备/视觉校验器；最终推送时间、费用上限和账号名单；签名公证所需 Apple Developer 身份。这些只阻止对应真实启用/验收，不阻止离线接口、界面、模拟测试及普通文字闭环开发。模型 ID 保留用户选择，每次接入时验证权限和能力，旧文档的日期核对不是账户可用证明。
