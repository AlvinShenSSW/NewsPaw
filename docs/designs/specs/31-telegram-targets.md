Special account bot_ids=None inherits its subscription, [] explicitly selects none. Each preview resolves global news_output_locale unchanged. Readonly calls never read Keychain/network.

Special set targets permits None inheritance only for already-classified account with compatible subscription; explicitadultinheritance action selects that known adult subscription's already-explicit targets, never normalgroupdefaults. Setting category targets is an explicit bulk edit of its CURRENT subscriptions (existing schema has subscription bot_ids, no separate category target field); return affected subscription IDs. Do not invent hidden defaults for newly created subscriptions. Special overrides are preserved; inherited specials follow changed subscription. User can edit a specific subscription to differ from its category siblings, preview exposes that matrix.
- Edit only target fields; test byte-equivalent rest of config (language,styles,profiles,schedules,source selection,priority). Existing CredentialManager serialization+CAS mutation and Store hooks; no parallel config authority or new schema. Empty/duplicate IDs and stale revision fail atomically with fixed diagnostics. T02 doesn't introduce speculative eventbus/targetgeneration table; T01 bindinggeneration already handles pause/unbind/token/ownerABA. Q01/Q02 own durable pending-task reconciliation.

Always clear subscription_id, bot_ids to [], style/times to None when the partition actually changes, preserve account ID/remoteID/handle/priority. Settingfalse removes this Bot from every adult subscription and adult special/ordinary explicit account botlist in same mutation; normal allocations untouched. Return affected scope IDs; no switchtoanotherBot, preserveallothernews settings. Preview impact before action available without mutation.
